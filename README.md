# Download Doc From Coretax

Python automation script for downloading Bukti Potong PPh documents from Coretax using Selenium.

## Features

* Filter document type
* Filter creation date
* Auto download documents
* Pagination support
* CSV logging
* Skip previously downloaded documents

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python unduh_bp4.py
```

## Notes

* Login to Coretax manually if needed
* Chrome browser required
